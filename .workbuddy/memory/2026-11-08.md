## 算法题多语言代码示例（可切换语言）

- 需求：算法题要有代码示例，支持 JS / TS / Java / Python / C++ 自由切换。
- 数据模型：`AnswerPart` 新增 `samples` 变体；`src/data/codeSamples.ts` 定义语言顺序、元数据（label/monaco/fence）、标签模板 `code` 去缩进、`pickSample` 缺失语言兜底。
- 偏好：`src/codeLang.ts` 用 localStorage + 订阅保存当前语言，`hooks.ts` 的 `useCodeLang()` 让所有代码块与练习页同步刷新。
- 代码数据：21 道算法题的五语言实现拆在 `src/data/algorithmCode.sort.ts` / `.struct.ts` / `.dp.ts`，由 `algorithmCode.ts` 汇总，`algorithm.ts` 在答案末尾注入并替换原来两处单语言 Java 片段。
- UI：`CodeBlock` 头部用 antd Segmented 切换语言并重新量高；`PracticePage` 加全局「代码语言」选择器；`format.ts` 复制答案只输出当前语言；`webpack.config.js` 注册 cpp 语言包保证 C++ 高亮。
- 约定：Java 片段默认写在类里、标准库已导入；C++ 片段按 C++17、默认常用头文件与 `using namespace std` 已就绪（README 已说明）。
- 验证：`npm test` 59 passed（新增 30 个测试，其中 21 个直接执行 JS 片段断言结果）、`npm run typecheck` 通过、`npm run build` 成功（仅既有体积警告）。
- 注意：工作区里 `plugin.json`、`src/index.tsx`、`types/fat-notes-sdk.d.ts` 在本次改动之前就是 modified 状态，未触碰。
